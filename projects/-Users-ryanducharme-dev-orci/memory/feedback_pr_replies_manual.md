Never post replies to GitHub PR comments, reviews, or threads unless Ryan explicitly says to. Ryan handles all PR communication himself.

**Why:** Ryan manages PR conversations directly. Unsolicited replies — even to acknowledge feedback that has been resolved — are not wanted.

**How to apply:** When addressing PR feedback, make the code changes and stop. Do not post a reply comment. If Ryan asks for a reply to be drafted, write it in Claude's voice (first person as Claude), not ghostwritten as Ryan — he will quote or paraphrase it himself.
